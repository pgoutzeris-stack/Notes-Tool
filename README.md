# ROOTS Notes Tool

Visuelles Notiz- und Canvas-Tool im ROOTS Design – integriert ins Intranet.

## Features

- Dashboard mit Ordnern, Clustern, Tags, Favoriten und Suche
- Canvas-Editor mit Formen, Sticky Notes, Text, Tabellen, Frames
- Intelligente Verbinder zwischen Objekten
- Inline-Textformatierung (fett, Listen, Überschriften)
- Anordnen, Drehen, Undo/Redo
- Präsentationsmodus über Frames
- Export: PNG, PDF, HTML, Markdown, JSON
- Supabase-Speicherung pro Nutzer (RLS)

## Supabase

Schema: `notes.folders`, `notes.documents`
